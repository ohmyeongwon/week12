# 점수 데이터 정제 및 분석

## 데이터 출처
- 수업 실습용 데이터: scores_2026.csv, mini.csv
- 받은 곳: 한국기술교육대학교 온라인 강의실에서 제공받은 12주차 폴더를 사용했다. 

## 데이터 크기
- scores_2026.csv: 원본 114행 → 정제 후 100행
- mini.csv: 정제 후 7행

## 열 설명
- 학번: 학생을 구분하는 번호
- 이름: 학생 이름
- 반: 학생이 속한 반
- 과목: 평가한 과목
- 점수: 해당 과목의 점수

## 정제 방법과 이유
1. 점수가 비어 있는 행을 삭제했다.
   - 평균 계산에 필요한 점수가 없기 때문이다.
2. 모든 열의 값이 같은 중복 행을 삭제했다.
   - 같은 기록이 여러 번 집계되는 것을 막기 위해서다.
3. 반과 과목 이름의 앞뒤 공백을 제거했다.
   - 같은 반과 과목이 서로 다르게 분류되는 것을 막기 위해서다.
4. 점수가 0~100 범위를 벗어난 행을 삭제했다.
   - 정상 점수 범위를 벗어난 값이 통계를 왜곡할 수 있기 때문이다.

## 분석 결과
- 전체 평균: 1반 78.24점, 2반 71.44점
- 과목별 평균: 모든 과목에서 2반이 높았다.
- 전체 평균만으로 판단하지 않고 과목별 평균과 인원 구성도
  함께 확인해야 한다.
